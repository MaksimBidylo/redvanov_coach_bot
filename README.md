# redvanov_coach_bot

Telegram-бот тренера на Go.

## Настройка

```sh
cp .env.example .env
```

Заполни `TELEGRAM_OWNER_ID` и `TELEGRAM_BOT_TOKEN` в `.env`.
Для доступа двух пользователей укажи их Telegram ID в `TELEGRAM_OWNER_ID` через запятую.
`DATABASE_URL` задаёт подключение бота к PostgreSQL.
Миграции схемы применяются автоматически при старте бота.

## Запуск

```sh
docker compose up -d --build --wait
```

PostgreSQL: `127.0.0.1:5432`, имя базы, пользователь и пароль — в `.env`.

Остановка — `docker compose down`. Данные базы сохраняются.

Для одного токена запускай один экземпляр бота.

## Возвраты

Полный возврат — удаление оплаты. Для частичного возврата уменьшите сумму исходной оплаты через редактирование: группа, дата получения и месяц занятий сохранятся.
